# 验证边界

## 已完成的真实验证

参考机器为 macOS 15.7 / arm64 / WeChat 4.1.15 (270115)，使用本人授权的独立签名副本，SIP 保持开启。一次 24 小时窗口读取了 179 条消息、32 位发言人，其中 1 条系统提示不计入发言人数。两片消息库均检查，目标群表存在于其中一片；三个所需数据库页认证、WAL 校验及 integrity_check 通过。当前 Codex 会话完整阅读并生成了实际六类报告文件，来源存在性与统计一致性通过，真实 PNG 全图尺寸及中文排版通过检查。

真实报告、群名、稳定群 ID、账号标识、设备私人路径和截图均不在此仓库。该结果只说明参考环境验证成功，不证明其他机器、版本或账号可直接兼容。

## 可复现的虚构验证

```bash
./wxreport demo
.venv/bin/python -m unittest discover -s tests -v
```

测试包括：SQLCipher 错误密钥/损坏页拒绝、加密 SQLite 与有效提交 WAL、全群名/同名群、秒/毫秒半开区间、跨分片去重、1502 条跨批读取、分片变化拒绝、正文前缀与嵌套引用、报告引用与统计、HTML 转义、临时明文文件未生成、启动器安全参数转义及账号/时间参数。PNG 尺寸检查需要先生成 demo，否则会明确跳过。

渲染器会在本机浏览器检查桌面/390px 移动端横向溢出、来源展开、页面错误、PNG 文件头尺寸；长报告在文字行间分段并记录连续范围。视觉观感及总结的语义支持仍需要会话检查。

开源打包时重新运行 24 项测试全部通过；离线虚构 demo 为 1920×4818 PNG，桌面/手机无横向溢出，来源展开通过。没有再次读取真实账号，也未把参考环境的验证当作公开版在全新机器上的完整安装验收。
